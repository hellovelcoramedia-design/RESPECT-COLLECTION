# RESPECT COLLECTION

Premium luxury fashion e-commerce experience for **RESPECT COLLECTION — Defined by Presence.**

## Stack
- Next.js + React + TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Included
- Cinematic homepage and editorial category sections
- Watches, Bags and Fragrance collection experiences
- Men/Women watch filtering
- Dynamic product detail routes
- Quick View modal
- Search overlay
- Wishlist interaction
- Shopping bag drawer with quantity-safe removal
- Responsive mobile navigation
- Accessibility-minded controls and reduced-motion support
- SEO metadata foundation

## Run locally
```bash
npm install
npm run dev
```

## Production
```bash
npm run build
npm start
```

Product content and imagery are centralized in `app/page.tsx` for easy replacement with real catalog data or a future Shopify/backend integration.
